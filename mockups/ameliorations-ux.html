💡 Autres suggestions (en plus)

  • 🧭 Onglets favoris : chacun épingle ses onglets les plus utilisés (la base existe déjà) → header moins chargé.
  • 📱 Mode cuisine/tablette : boutons plus gros, infos essentielles, pour l'usage au doigt en prod.
  • ↩️ Annuler (undo) : après une suppression/un changement, un « Annuler » de 5 s (évite les erreurs).
  • 🗂️ États vides utiles : au lieu de « Aucune commande », un message + un bouton d'action (« Prendre une commande »).
  • 🎨 Couleurs/badges unifiés : même code couleur partout (rouge=urgent, jaune=en attente, vert=ok).
  • ⌨️ Raccourcis : Échap ferme les fenêtres, flèches naviguent (déjà partiel), Ctrl+K = recherche.
