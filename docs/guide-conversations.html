📱 Guide — Conversations WhatsApp

Comment discuter avec les clientes de Lily Gourmet depuis l'app : répondre, envoyer photos/vocaux, utiliser les phrases types, gérer les paiements. (Les écrans ci-dessous sont des illustrations.)

4

3. Les boutons d'envoi

📎 Joindre — une image ou un PDF (max 5 Mo). · 😊 Emojis. · 💬 Phrases types — insérer une réponse pré-écrite. · ✨ Suggérer — l'IA propose 3 réponses, tu choisis. · 🎤 Vocal — enregistrer un message audio (✓ envoyer / ✕ annuler).

🎤 Si l'app prévient que l'audio n'est pas compatible WhatsApp, ré-enregistre — sinon la cliente risque de ne pas l'entendre.

4. Les phrases types (réponses rapides)

Des messages tout prêts (RIB, modes de paiement, etc.) pour répondre en 1 clic.

1
Bouton 🗣️ Phrases (en haut de la liste) pour les créer/modifier.
2
Donne un nom court (ex. « RIB ») + le texte (+ une photo si besoin).
3
Dans une conversation, bouton 💬 → choisis la phrase → elle s'insère.

5. Démarrer un nouveau message (modèles)

Bouton + Nouveau message. Tu cherches une commande (n° S…, nom, téléphone) → l'app pré-remplit le numéro et choisit le bon modèle WhatsApp (confirmation, devis, relance…). Tu vérifies, puis Envoyer.

📅 Fenêtre 24 h : WhatsApp n'autorise un message « modèle » que si la cliente a écrit dans les dernières 24 h. Au-delà, passe par un modèle (pas un message simple) pour relancer.

6. Les paiements (preuves de virement)

1
Quand une cliente envoie une preuve (capture/PDF de virement), clique le bouton 💰 sur ce message.
2
Remplis n° de commande, nom, montant → « Transférer aux paiements ».
3
Dans l'onglet 💰 Paiements → « À valider » : tu cliques Valider ✅ ou Refuser ❌ (avec motif).

7. Bon à savoir

  • Transférer un message 🔗 : renvoyer un message à une autre cliente.
  • Supprimer un message 🗑 : l'app tente aussi de l'effacer chez la cliente (possible ~15 min après l'envoi).
  • Notifications : un petit bandeau apparaît en haut quand une cliente écrit ; clique dessus pour ouvrir la discussion.
  • Qui peut quoi : voir Conversations, marquer une preuve, voir les paiements, valider les paiements — chaque droit se règle par l'admin dans Utilisateurs.
